Backend

Supabase FlavorGraph — 6,600+ ingredient nodes with 300-dimensional embeddings, 123k weighted pairing edges. Shared by both apps. Read-only anon key, safe in client.

Stack

Plain HTML / CSS / JS. No framework, no build step, no npm. Hosted on Vercel; auto-deploys on push to main. tokens.css shared by both apps.

Data

Park et al., FlavorGraph, Scientific Reports 2021. 102 IBA cocktail recipes in Supabase. FlavorGraph trained on 1M+ recipes and 1,500 flavor molecules.
